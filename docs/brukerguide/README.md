# Norsk brukerguide for VPM Tolkning

Guiden forklarer arbeidsflyten fra Archer-eksport til pasientrapport med detaljerte
trinn, 22 unike skjermbilder, røde rammer og nummererte markeringer.

- [PDF: 41 sider med klikkbar innholdsfortegnelse](VPM_Tolkning_Brukerguide.pdf)
- [Nettleserversjon med bildeforstørring](VPM_Tolkning_Brukerguide.html)

Last ned HTML-filen og åpne den lokalt i en nettleser. GitHub viser HTML-kilden,
ikke den interaktive guiden. Alle bilder er innebygd i HTML-filen, og guiden kan
leses uten nettverk. PDF-lenken øverst fungerer når PDF-filen ligger i samme mappe.

## Omfang og versjon

Utgave 1.0, dokumentert 18. oktober 2026 mot appen i commit `dc32d9d`.
Guiden dekker Import, Excel-gjennomgang, X-valg, kildevalg og innlogging,
databasesøk, prioritert pasientkø, pause/stopp/gjenopptak, rapporter,
innstillinger, artefaktregler, logg og feilsøking.

Bildene bruker syntetiske demonstrasjonsdata. Aktive søketilstander er iscenesatt
i appens faktiske grensesnitt. Excel-bildene viser syntetiske filer laget av
appens rapportkode. Ingen eksterne databasesøk eller kliniske resultater er
verifisert som del av dokumentasjonsarbeidet.

## Vedlikehold

`guideinnhold.json` inneholder teksten per kapittel. `bilder/` inneholder de
annoterte skjermbildene. PDF og HTML er ferdige leveranser og må oppdateres sammen
med innholdsgrunnlaget når knapper, arkfaner eller arbeidsflyt endres.

Kontroller spesielt sidehenvisninger, nummermarkeringer, variantidentitet,
rapportnavn og at det ikke har kommet med pasient- eller kontoopplysninger.
Råbilder, arbeidsfiler og demonstrasjonsarbeidsbøker er ikke inkludert.
